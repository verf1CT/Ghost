# 👻 GhostGPS

Подмена геопозиции iPhone, управляемая **с самого телефона**. Mac выступает «мотором»:
он держит связь с iPhone, а ты в Safari на телефоне тыкаешь по красивой карте — точки,
жилые дома и зацикленные трассы (гонишь 110 по кольцу вокруг города бесконечно).

Работает по Wi-Fi (в т.ч. если раздать интернет с самого iPhone) — кабель после первого
коннекта не нужен.

## Запуск с нуля на Mac (Xcode уже стоит)

Ниже — весь путь от чистого Mac до зелёного статуса в Safari. Xcode уже установлен, так что
`git` и `python3` у тебя есть — отдельно ставить ничего не нужно.

### Шаг 1. Один раз настроить iPhone
1. **Developer Mode:** на iPhone → Настройки → Конфиденциальность и безопасность → Режим
   разработчика → включить → перезагрузить телефон и подтвердить.
2. **Доверие:** подключи iPhone к Mac кабелем, на телефоне нажми **«Доверять»** и введи код.
   Это нужно сделать кабелем только в первый раз — дальше всё работает по сети.
3. **Одна сеть:** Mac и iPhone в одной Wi-Fi. Можно наоборот — раздать интернет с iPhone и
   подключить Mac к этому хотспоту.

### Шаг 2. Проверить, что Mac видит телефон (необязательно, но полезно)
В Терминале:
```bash
xcode-select -p            # должен вывести путь к Xcode/CLT, а не ошибку
python3 --version          # 3.9+ — идёт с Xcode
```
Если `xcode-select -p` ругается — выполни `xcode-select --install` и повтори.

### Шаг 3. Склонировать и запустить — одна команда
```bash
git clone https://github.com/<ТВОЙ_ЛОГИН>/Ghost.git && cd Ghost && bash run.sh
```
Что делает `run.sh` сам:
- создаёт виртуальное окружение `.venv` и ставит в него `pymobiledevice3`;
- поднимает туннель к iPhone (`pymobiledevice3 remote tunneld`) — **спросит пароль Mac**
  для `sudo`, это нормально и обязательно для iOS 17+;
- запускает сервер и печатает адрес вида `http://192.168.x.x:8765`.

> Пароль не отображается при вводе — просто набери и нажми Enter.

### Шаг 4. Управлять с телефона
1. Открой напечатанный адрес в **Safari на iPhone**.
2. Кружок статуса вверху должен стать зелёным (**Готов**).
3. Тыкай по карте, выбирай дом или жми на трассу — телефон окажется там / поедет.
4. **СТОП** — остановить движение, **Сброс** — вернуть реальную геопозицию.

## Повторный запуск после перезагрузки
Просто снова в папке `Ghost`:
```bash
bash run.sh
```
Заново склонировать не нужно — окружение уже создано, поднимется быстро.

## Если что-то пошло не так
- **Статус не зеленеет.** Проверь по порядку: кабель/доверие при первом коннекте, включён ли
  Developer Mode, в одной ли сети Mac и iPhone, поднялся ли туннель — лог в
  `/tmp/ghost_tunneld.log`.
- **Mac не видит iPhone.** Выполни `pip install -U pymobiledevice3` и `pymobiledevice3 usbmux list`
  — телефон должен появиться в списке. Если нет — переподключи кабелем и снова нажми «Доверять».
- **`bash run.sh` падает на старте.** Запусти `xcode-select --install`, дождись установки и
  повтори.
- **Адрес из терминала не открывается на телефоне.** Убедись, что это адрес `192.168.x.x`
  (локальная сеть), а не `127.0.0.1`, и что firewall на Mac не блокирует порт.

## Заметки
- Яндекс.Карты используют свою геолокацию и подмену игнорируют — это ожидаемо.
- Порт по умолчанию `8765`.
