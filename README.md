# 👻 GhostGPS

**Spoof your iPhone GPS location directly from your Mac — no jailbreak, works over Wi-Fi!**

> [!NOTE]
> **GhostGPS** позволяет подменять геопозицию iPhone, управляя процессом **прямо с телефона**. Mac выступает лишь «мотором»: он держит связь с iPhone, а ты в Safari на телефоне тыкаешь по красивой карте — ставишь точки, выбираешь жилые дома или настраиваешь зацикленные трассы.

Работает по **Wi-Fi** (в т.ч. если раздать интернет с самого iPhone) — кабель после первого подключения больше не нужен.

## 🚀 Запуск с нуля на Mac (Xcode уже стоит)

Ниже — весь путь от чистого Mac до зелёного статуса в Safari. 
*(Предполагается, что Xcode уже установлен, так что `git` и `python3` у тебя есть — отдельно ставить ничего не нужно).*

### Шаг 1. Один раз настроить iPhone 📱

1. **Developer Mode:** на iPhone → `Настройки` → `Конфиденциальность и безопасность` → `Режим разработчика` → включить → перезагрузить телефон и подтвердить.
2. **Доверие:** подключи iPhone к Mac кабелем, на телефоне нажми **«Доверять»** и введи код. Это нужно сделать кабелем *только в первый раз* — дальше всё работает по сети.
3. **Одна сеть:** Mac и iPhone должны быть в одной Wi-Fi сети. (Можно наоборот — раздать интернет с iPhone и подключить Mac к этому хотспоту).

### Шаг 2. Проверить зависимости на Mac 💻
В Терминале:
```bash
xcode-select -p            # должен вывести путь к Xcode/CLT, а не ошибку
python3 --version          # 3.9+ — идёт вместе с Xcode
```
> [!TIP]
> Если `xcode-select -p` ругается — выполни `xcode-select --install` и повтори.

### Шаг 3. Склонировать и запустить — 1 команда ⚡
```bash
git clone https://github.com/verf1CT/Ghost.git && cd Ghost && bash run.sh
```

**Что делает `run.sh` под капотом:**
- Создаёт виртуальное окружение `.venv` и ставит в него `pymobiledevice3`.
- Поднимает туннель к iPhone (`pymobiledevice3 remote tunneld`) — **спросит пароль Mac** для `sudo`, это нормально и обязательно для iOS 17+.
- Запускает сервер и печатает адрес вида `http://192.168.x.x:8765`.

> [!IMPORTANT]
> Пароль не отображается при вводе — просто набери его вслепую и нажми Enter.

### Шаг 4. Управлять с телефона 🗺️
1. Открой напечатанный адрес в **Safari на iPhone**.
2. Кружок статуса вверху должен стать зелёным (**Готов**).
3. Тыкай по карте, выбирай дом или жми на трассу — телефон моментально окажется там.
4. **СТОП** — остановить движение, **Сброс** — вернуть реальную геопозицию.

## 🔁 Повторный запуск после перезагрузки
Просто снова выполни в папке `Ghost`:
```bash
bash run.sh
```
Заново клонировать не нужно — окружение уже создано, сервер поднимется мгновенно.

## 🛠 Если что-то пошло не так

- 🔴 **Статус не зеленеет.** Проверь по порядку: кабель/доверие при первом коннекте, включён ли Developer Mode, в одной ли сети Mac и iPhone, поднялся ли туннель — лог в `/tmp/ghost_tunneld.log`.
- 🔴 **Mac не видит iPhone.** Выполни `pip install -U pymobiledevice3` и `pymobiledevice3 usbmux list` — телефон должен появиться в списке. Если нет — переподключи кабелем и снова нажми «Доверять».
- 🔴 **`bash run.sh` падает на старте.** Запусти `xcode-select --install`, дождись установки и повтори.
- 🔴 **Адрес из терминала не открывается на телефоне.** Убедись, что это адрес локальной сети `192.168.x.x` (а не `127.0.0.1`), и что firewall на Mac не блокирует порт.
